I'm a full stack engineer based in the Philippines with **10+ years of web development** and **5+ years of cross-platform mobile development**. I've led front-end teams, migrated legacy apps to modern React, shipped SaaS products, and deployed containerized apps to AWS and Kubernetes.

- Currently focused on **Next.js, React, Django REST, Node/Express, and PostgreSQL**
- Comfortable with the full delivery pipeline: **Docker, Nginx, AWS, Kubernetes, and GitHub Actions CI/CD**
- Built mobile apps in **Flutter (Dart)**, **React Native (Expo)**, Java, Kotlin, and Swift
- Exploring **on-device machine learning in Flutter** with LiteRT (real-time object detection from the camera)

- Enjoy mentoring developers and working closely with cross-functional teams
